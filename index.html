    Methods

    link

    Every number on this page comes from Taskmarket's public API at https://api.taskmarket.dev — no key, no wallet, no login. The API does not accept browser requests from other sites, so this site fetches the data on its server (a serverless function) and caches it: the page is refreshed at least hourly and cached for at least 60 seconds. The data as of time at the top is when the server last fetched.

    Endpoints used:

    Money is shown in dollars. Rewards are paid in a stablecoin — OUSD on Tempo, USDC on Base — and the API reports volumes in base units (1,000,000 base units = $1). The time series, heatmaps and activity feed are platform-wide: the API returns the same values for either chain, which was verified on 2026-11-24. Task lists, open rewards and posters-per-week are computed per chain from /api/tasks. No names or identities are attached to wallet addresses. No number here is invented; anything that cannot be reproduced from the API is not shown.

    Stack: static HTML/CSS/JS plus one Node serverless function (api/data.js), no dependencies, no build step, no analytics, no tracking. Deploy: vercel --prod. Source: github.com/georgeonweb3/taskmarket-live-visualizer (MIT).

    Made for a paid Taskmarket bounty. This is not an official Taskmarket product.
